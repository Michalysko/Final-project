# Insurance App

Web application for managing insured people, insurance types, and insurance contracts.

## Technologies

- Python
- Django
- Django REST Framework
- SQLite
- React
- JavaScript
- Vite

## Features

- User login
- Administrator and client roles
- Create, edit, delete, and view insured people
- Create, edit, delete, and view insurance types
- Create, edit, delete, and view insurance contracts
- Czech and English language switcher

## Project Structure

- `backend/` - Django REST API
- `frontend/` - React frontend
